# Інструкція користувача

## 1. Вступ
Цей документ містить базові інструкції щодо використання навчального вебзастосунку **KOP_GRING_FOR_60**.

Проєкт створений у межах навчального курсу та доповнений документацією відповідно до вимог дисципліни.

---

## 2. Системні вимоги
Для запуску проєкту необхідно:
- Node.js
- npm
- Git
- сучасний веббраузер

---

## 3. Встановлення

Клонування репозиторію:

```bash
git clone https://github.com/sokave/KOP_GRING_FOR_60.git
cd KOP_GRING_FOR_60
```
### Встановлення залежностей:

```bash
  npm install
```

## 4. Запуск застосунку

```bash
   npm run dev
```

---
Після запуску відкрий у браузері:

http://localhost:5173/

---

## 5. Основний функціонал

---
