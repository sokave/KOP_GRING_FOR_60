# Документ специфікації системи (SSD)

## 1. Опис системи
Цей документ описує технічну реалізацію та архітектуру проєкту **TicTacToe**.

---

## 2. Архітектура системи
Тип системи:
- односторінковий вебзастосунок (SPA)

Використані технології:
- React
- Vite

---

## 3. Основні компоненти
- App — головний контейнер застосунку
- Board — логіка ігрового поля
- Square — окрема клітинка
- CookieBanner — компонент згоди на cookies

---

## 4. Потік даних
- користувач взаємодіє з інтерфейсом;
- події викликають зміну стану;
- компоненти перерендерюються.

---

## 5. Маршрутизація
Застосунок використовує маршрути:

- `/` — головна сторінка
- `/game/:id` — сторінка гри
- `/scoreboard` — сторінка результатів

---

## 6. Управління станом
Стан реалізовано через:
- React state
- Redux Toolkit

---

## 7. Залежності
Основні бібліотеки:
- react
- react-router-dom
- redux toolkit
- styled-components
- react-cookie-consent

---

## 8. Безпека
- персональні дані не обробляються;
- реалізовано cookie banner;
- автентифікація відсутня.

---

## 9. Запуск системи

```bash
  npm install
  npm run dev
```

---

## 10. Обмеження
- відсутній бекенд;
- відсутнє збереження даних;
- проєкт має навчальний характер.

---
